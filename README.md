«SysPulse — System Information & Monitoring Tool»

A lightweight command-line tool designed to display useful system information directly from the terminal.

---

✨ Features

- 🖥️ System information
- ⚡ CPU information
- 💾 Memory information
- 💿 Storage information
- 🌐 Network information
- ⏱️ System uptime
- 📊 Terminal-based output
- 🐧 Linux / Termux friendly
- 🚀 Simple installation
- 🔧 Lightweight Bash tool

---

📦 Installation

1. Clone the repository

git clone https://github.com/dhannjayuphade/SysPulse.git

2. Enter the directory

cd SysPulse

3. Give execution permission

chmod +x syspulse.sh

4. Run SysPulse

./syspulse.sh

---

⚡ Quick Install

You can also use:

git clone https://github.com/dhannjayuphade/SysPulse.git && cd SysPulse && chmod +x syspulse.sh && ./syspulse.sh

---

🛠️ Usage

After installation:

cd SysPulse
./syspulse.sh

If you are already inside the repository:

./syspulse.sh

---

📱 Termux

SysPulse can be used in Termux on Android.

Install Git if required:

pkg update
pkg install git

Then install SysPulse:

git clone https://github.com/dhannjayuphade/SysPulse.git
cd SysPulse
chmod +x syspulse.sh
./syspulse.sh

---

🔄 Update

To get the latest version:

cd SysPulse
git pull

Then run:

./syspulse.sh
